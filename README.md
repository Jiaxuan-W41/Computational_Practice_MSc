# Computational_Practice_MSc
This repository contains selected computational exercises from my MSc training in Theoretical and Computational Chemistry. The code is based largely on work I originally completed during the course and was later revisited, reorganised and annotated as part of my own revision and programming practice.
I am mindful of academic-integrity and course-material restrictions. Therefore no tutorial sheets, assignment briefs, official solutions, instructor-provided notebooks/templates, or starter code are included. The public repository focuses on my own implementations, explanations, and reflections on the limitations and improvements of my original approaches.
